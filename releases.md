# Release notes

Current version: **0.1.0**


**0.2.0**, *??*: utility scripts for building dot graphs from cited references in a corpus.


**0.1.0**, *Sept. 5, 2026*: Initial release. Reads CEX corpora, analyzes citable passage with `spacy` tools, extracts syntactic data into a `SyntaxGraph` structure. Supports import `SyntaxGraph` into polars dataframes, diagramming with `graphviz`, and diagramming with Mermaid.
